# Crypto Price Tracker

A simple Python application that retrieves cryptocurrency prices using the Coinbase API.

## Features

* Get real-time cryptocurrency prices
* Support for multiple cryptocurrencies
* Compare multiple cryptocurrencies
* Detect price increases and decreases
* Calculate percentage price changes
* Handle API and network errors
* Simple command-line interface

## Supported Cryptocurrencies

* Bitcoin (BTC)
* Ethereum (ETH)
* Solana (SOL)
* XRP
* Dogecoin (DOGE)
* Cardano (ADA)

## Technologies

* Python
* Requests
* REST API
* JSON
* Coinbase API

## Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/crypto-price-tracker.git
```

Go to the project directory:

```bash
cd crypto-price-tracker
```

Install the required package:

```bash
pip install requests
```

Run the application:

```bash
python main.py
```

## Usage

After running the program, choose a cryptocurrency from the menu.

You can also compare multiple cryptocurrencies by selecting option 7 and entering multiple numbers.

Example:

```text
Your selection: 1 2 3
```
